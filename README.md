# python-machine-learning-assignment
1. What is supervised machine learning?
   It is a type of machine learning where a model learns from labelled data to make predictions.
   
2. What is unsupervised machine learning?
   It is a type of machine learning where a model finds patterns or groups in unlabelled data.
   
3. Explain the difference between supervised and unsupervised learning. Supervised learning uses labelled data, while unsupervised learning uses unlabelled data.

4. Why is Linear Regression considered supervised learning?
 Because it learns from labelled data to predict numerical values.

5. Why is K-Means considered unsupervised learning?
 Because it groups data based on similarities without predefined labels.

6. What is the difference between fit() and predict()?
    
•	fit() trains the model using data.
•	predict() uses the trained model to make predictions.

7. Give two real-world applications of supervised learning and two of unsupervised learning.
•	Supervised learning: Email spam detection and house price prediction.
•	Unsupervised learning: Customer segmentation and grouping similar news articles.
